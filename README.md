# 🐱 ماینر اتومات میو

ربات اتومات برای گروه میو

## نصب روی Render

1. این ریپازیتوری رو Fork کن
2. برو به [render.com](https://render.com)
3. New → Web Service
4. ریپازیتوری رو انتخاب کن
5. تنظیمات رو بذار و Deploy کن

## کاربران

کاربرا با ربات `@mew_info_bot` ثبت‌نام میکنن و اطلاعاتشون ذخیره میشه.

## فایل‌ها

- `main.py` - ربات اصلی
- `bot_handler.py` - ربات دریافت اطلاعات
- `users.json` - اطلاعات کاربران
- `sessions/` - سشن‌های کاربران
